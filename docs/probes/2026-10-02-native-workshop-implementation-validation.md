# Nico工坊原生成就本地验证

日期：2026-10-02。Forge `0.6.5`，机械飞升 `0.1.18`；配套模组矩阵 `1.1.0`、物流脉络 `0.2.0`、合成扩展 `0.9.14`。目标 Demo Steam Build `25382790`。

## 实现范围

- Forge 内置全开局名片 `nicokobo.forge.nico_card`，沿用现有 2×1 模板和图标，不兼容旧 ID 或旧发放记录。满背包后延迟重试，当前周目发放确认后不补发遗失名片。
- 默认打开“原版”；机械飞升保留自己的页面，普通开局中展示未开放。
- [方案](../WORKSHOP_ACHIEVEMENT_DESIGN.md)中的十项成就分别判定，主题连线不作为前置。达成事实与领取状态分开保存。
- 老鼠读取实际克数；金属锭读取原生完美纯度；酒要求同一瓶发酵完成、非假酒、最高品质且陈化至少十天，自酿的 `wine_bottle` 也可判定。五种工具必须同时持有。
- 通关只观察本周目的 `buyout`／`buyout_mortgage` 成功结局，奖励为工坊展示的通关纪念徽章。
- 整份奖励预检后交付，保存待确认记录及具体物品 UID，读回原生存档文件后提交领取状态。恢复只确认原事务，不重新生成奖励。公共 `InventoryTransfer` 仍为 `false`。
