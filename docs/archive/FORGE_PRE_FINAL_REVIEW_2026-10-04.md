## 夜间商店库存修复（源码已编译，未安装）

移除购买后的自动补货、延迟队列、重试和逐帧更新入口。新增商品只在原生夜间商店生成库存时加入；白天购买不会触发夜间商店上架。`Repeatable` 仍表示下次原生库存生成时可再次上架，`Unique` 保留已有物品过滤。

上架前按待售归属预检货架空间，放不下的商品跳过；原生摆放接管物品后，由原生处理拒绝时的销毁，避免二次销毁。17 项新增商店离线回归、领域检查及 143 项接口元数据检查通过，Forge Release 编译为 0 警告、0 错误。本次未重新打包或安装，购买后机器贴图现象尚待实机复测。

Forge 与统一包三份内容 Mod Release 编译均为 0 警告、0 错误，规范混淆和配套静态检查通过，程序集版本与 MelonInfo 一致。已在游戏关闭时安装统一包四份 DLL，各文件与发布包一致，各程序集只有一份启用 DLL。删除旧文件被自动审批拦截后，旧 Forge `0.6.15` 与机械飞升 `0.1.36` 改为 `.dll.disabled`。本版尚未启动游戏复测；下方原生验收记录适用于此前 Forge `0.6.15` 审查产物。

## 开局选择栏优化（已安装，待实机验证）

Forge 在原版新游戏菜单打开后统一处理选择栏，原版和内容 Mod 卡片共用 44–52 的自适应行高；内容超出时启用滚轮、裁剪和细滚动条。重新打开菜单回到顶部，新增卡片或窗口尺寸变化时重新排版。机械飞升移除自身布局实现，只保留卡片文本和选择逻辑。

本次 `Build-P0.ps1` 的 143 项适配签名检查、领域检查、11 项 HookGuard 检查，以及核心和四个示例编译通过。机械飞升使用本次 Forge DLL 的 Release 编译为 0 警告、0 错误。检查工具仍提示 .NET 6 支持期限和 DiagnosticSource 版本警告。

随后通过 `Build-MechcoreProtocol.ps1 -OnlyProject mechcore-protocol` 重新生成统一包：三份内容 Mod Release 编译为 0 警告、0 错误，矩阵与合成扩展混淆、熔炉／液体签名和机械飞升主菜单生命周期检查通过。已在游戏关闭时安装 Forge `0.6.16`、机械飞升 `0.1.37`、矩阵 `1.1.1` 和合成扩展 `0.9.39`；四份安装 DLL 均与本次发布包一致，各程序集只有一份启用 DLL。本次构建记录为 `_build/mechcore-obfuscation/20261004-115722-09d58f78/`；尚未启动游戏验证选择栏效果。

### 图标重叠修复（已安装，待视觉复核）

用户截图显示图标与名称重叠。读取游戏 `level0` 的原版 UI 确认：按钮原宽 258，图标使用中心锚点与 X=-103，文字区域左边距约 48；选择栏拉宽后图标右移，而文字起点不变。现将图标固定在左侧，尺寸 32、左边距 10，文字从 X=52 开始，二者间隔 10；图文垂直居中，行高和滚动逻辑继续共用。

Forge Release 编译为 0 警告、0 错误，统一发布流程的内容编译、混淆和静态契约检查通过。已在游戏退出后重新安装统一包四份 DLL，4/4 与新包一致，各只有一份启用文件；本次构建记录为 `_build/mechcore-obfuscation/20261004-121119-0a52560c/`。修正后的视觉效果尚未实机复核。
