# Nicokobo Forge 当前进度

更新：2026-10-04。当前源码 Forge `0.6.16`，配套机械飞升 `0.1.37`、模组矩阵 `1.1.1`、物流脉络 `0.2.1`、合成扩展 `0.9.39`。目标 Demo Steam Build `25382790`。本地安装与验证范围分别记录，尚未线上发布。

## Forge 0.6.16 启动兼容修复

修复互操作程序集哈希变化导致受支持的游戏版本被误停用的问题：Forge 和机械飞升使用游戏本体识别版本，生成 DLL 的哈希保留为诊断信息；实际接口与原生补丁入口校验继续生效。机械飞升 `0.1.37` 最低依赖 Forge `0.6.16`，合集 README 和 changelog 更新为 `0.0.2`。

Forge 与统一包三份内容 Mod Release 编译均为 0 警告、0 错误，规范混淆和配套静态检查通过，程序集版本与 MelonInfo 一致。已在游戏关闭时安装统一包四份 DLL，各文件与发布包一致，各程序集只有一份启用 DLL。删除旧文件被自动审批拦截后，旧 Forge `0.6.15` 与机械飞升 `0.1.36` 改为 `.dll.disabled`。本版尚未启动游戏复测；下方原生验收记录适用于此前 Forge `0.6.15` 审查产物。

## 当前实现

- 机器模板、物品／液体／电力事务、追加配方和原生生命周期分派；内容方持有配方、质量与效果。
- 同帧库存读取、模组准入与计算／学习事件、图集、ES3 只读回查和原生补丁入口检查。
- Nico 工坊全开局名片、原版与伪人独立页、原生成就和本周目收购预算奖励。
- 36 条 NPC 扩展供货入口；矿工整批只抽一种矿物，持有名片时过滤重复名片；农夫、水商和冰矿工保留原版供货。
- 物流脉络具备物品声明和网络领域规则；原生搬运、网络货物存储及电量适配未实现，`InventoryTransfer` 为 `false`。

## Forge 0.6.15 审查

从 Forge `b57a1cc`、内容仓库 `5b7cc4a` 建立独立副本，原仓库、正式安装 DLL 与玩家存档保持原样。已移除三个无引用内部入口并修正文档中的过期最低依赖；没有删除正在使用的存档兼容逻辑。

候选修复同机生产重入、模组准入回调重入冲突及空物品标识中断机器扫描；合成扩展安装熔炉 Hook 前检查原生执行地址。新增兼容的 `PerOutputWithOverhead` 计价接口，由内容方提供批次加值。400 条配方的同一夹具，源枚举次数从 3 次降至 1 次，阴性标签读取从 400 次降至 1 次；没有推断游戏帧率提升。

框架与四个内容 Mod 的领域检查、11 项独立 HookGuard 检查、六个示例编译和规范 Release／Obfuscar 构建通过。原生测试后执行了独立第七轮审查，并以修正后的最终 DLL 重跑核心路径。

## 原生验收边界

实际启动隔离的游戏副本，逐进程验证可执行文件路径、Unity 公司／产品路径、全局 ES3、存档索引和 Mod 数据目录。542 个正式存档／安装保护文件在各轮退出后的哈希均未改变，没有执行旧备份还原。

通过的范围包括加载注册、30 条配方及磁带变体、代表性事务失败和重入、六台机器实际过夜、固定／连续模组、部分布局与专用机器效果、义体持有效果、伪人夜间结算与修补胶、手册原生回调和渲染，以及真实 ES3 保存后另一进程读档。逐配方测试直接调用运行时；过夜与读档调用游戏原生流程。手册以原生物品回调及 `Button.onClick` 驱动。

真实鼠标拖放、Escape／窗口外手势、中文布局、其余布局节点、完整玩家解码 UI、随机事件结果、NPC 交易、工坊奖励及脑机接口安装／卸载等未完成原生验收。物流原生搬运尚未实现。本轮结果不能代替这些分支的实机证明。详细覆盖、失败历史与截图保存在本次独立审查目录及内容仓库 `docs/probes/2026-10-04-forge-mechcore-native-audit.md`。
