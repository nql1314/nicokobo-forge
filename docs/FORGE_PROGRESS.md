## 2026-09-27 审查修复

- 网络升级购买失败时，先核对周目、槽位、存档对象和升级对象，再恢复节点状态、信用点及野地恩惠；补偿调用原生保存后，只在目标 `.es3` 槽位回读匹配时报告 `RolledBack`。无法确认文件结果时报告 `PersistenceUncertain`。
- 必需的网络升级 Harmony 钩子安装失败时，撤销本次已安装的回调并关闭能力门控。冲突 ID 的原生升级、解锁动作及 UI 元素不被 Forge 覆盖；Forge 自身升级遇动作或 UI 冲突时停止购买路径。
- 工坊切换到首个可用标签页时复用同轮已校验的 `Snapshot()`，避免再次调用内容提供方得到空值或无效数据。
- 额外资源由内容 Mod 的 `TryConsumeRequirement` 管理；回调返回失败或抛异常前必须自行撤销已发生的资源变更。Forge 的存档回读只核对原生升级状态、信用点和野地恩惠，不能证明内容侧材料和效果已持久化。
