## 当前实现

通用注册、内容应用通知、生命周期、模组、文本、开局、周目数据、机器、电量、液体、生产价值和工坊分别由公共 API 提供。原生目录按能力门控接入，内容方拥有配方、效果、成本与奖励。详见 [API 职责](API_BOUNDARIES.md)和[范围](SCOPE.md)。

自定义机器使用原版 UI 模板，支持物品／液体输入和物品／容器输出，每台每夜最多尝试一批。原版熔炉扩展由合成扩展持有，只复用通用批次事务。机器定义的 `ProductionMarkupPercent` 随批次上下文传给本机与追加配方。容器输出可按实际取出的组分生成内容，转换规则由内容方决定。

库存快照与完整单件搬运预检已开放；`InventoryTransfer` 仍为 `false`。Forge 补充垃圾桶清理保持停用。

Forge 内置 Nico工坊名片（`nicokobo.forge.nico_card`）和 10 项原版成就，使用独立周目记录，分别展示达成与领奖。全开局入口与机械飞升独立页面已分开；名片和奖励整份预检、原生交付、存档文件读回，以及待确认事务恢复已接入源码。游戏内验收待完成。
